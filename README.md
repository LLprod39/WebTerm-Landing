# WebTerm Landing

Отдельная статическая лендинг-страница для [WebTerm](https://github.com/LLprod39/WebTerm).

**Live:** https://llprod39.github.io/WebTerm-Landing/

Не является частью приложения. Код продукта здесь не меняется.

## Online

Публикуется через **GitHub Pages** из ветки `main` (корень репозитория).

После правок:

```bash
git add -A
git commit -m "Update landing"
git push
```

Сайт обновится за 1–2 минуты.

## Локально

```bash
npx --yes serve .
# или
python -m http.server 5500
```

## Состав

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка |
| `css/styles.css` | Стили |
| `js/main.js` | Вкладки, copy, меню |
| `assets/favicon.svg` | Иконка |

## Визуальный стиль

**Flow Dark** — дефолтная тема продукта WebTerm:

- нейтральный графитовый фон и поверхности
- белый основной action, синий AI-акцент, зелёные статусы
- **Manrope** (display) + **Inter** (UI) + **JetBrains Mono**
- те же базовые цвета, радиусы и elevation, что в интерфейсе платформы

Лендинг включает интерактивную карту возможностей, схему движения и хранения данных,
описание защиты, устройство проекта и варианты развёртывания.
